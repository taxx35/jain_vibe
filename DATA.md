# Data

The antibody and assay tables used in the MSc project and follow-on manuscript are not included in this public repository.

Some antibody sequences, VIBE measurements and matched developability-assay data were supplied through a university/industry collaboration. Those materials remain private.

## Public example data

`examples/synthetic_antibodies.csv` is generated by `examples/make_synthetic_demo.py`.

It contains:

- synthetic aligned VH sequences;
- synthetic aligned VL sequences;
- synthetic sequence-derived numeric features;
- a synthetic positive continuous target named `VIBE1`;
- planted family labels used only to validate the benchmark construction.

The synthetic rows are not real antibodies and the generated target is not an experimental measurement. No collaboration data are embedded in the generator.

## Reproducibility

Regenerate the example with:

```bash
python examples/make_synthetic_demo.py
```

The generator uses a fixed random seed so the public benchmark is reproducible.
